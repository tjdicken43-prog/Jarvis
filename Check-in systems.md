# Check-in systems

What gyms use at the front desk, and how [[Front-desk reader]] handles each.

## Ashbourne (J Street)
- Front turnstile logs as **Zone 1**. Iron Street is on the same Ashbourne system, so only Zone 1 counts at [[J Street Gym]].
- Live Entry pop-up: Membership No, Entry Time, Entry Message (the zone), Admission Message (where "Membership Expired" shows).
- Visit Log columns: Mem No, Name, Status, Entry Date, Zone, Entry Msg, Admission.
- J Street hasn't installed Ashbourne's update yet ("Update Available" in the top bar). The reader handles both looks.
- Ashbourne hasn't given data access, so scans are read from the screen instead.
- No member photos on accounts.

## Anything else
Taught on install day from one test scan. If an update renames things on screen, the reader either keeps reading or says "teach it again". It never makes up scans.
