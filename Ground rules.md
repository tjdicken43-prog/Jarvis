# Ground rules

Things that stay true no matter what. Part of [[SecurityAI]].

- Never auto-loosen detection.
- Self-repair never touches detection or AI instructions, sign-in and security, encryption, prices and payments, or privacy and retention. Code changes need TJ's approval.
- Member numbers are scrambled on the Pi; screen pictures are never saved or sent.
- The camera password is only ever sent to the recorder.
- Never put passwords, API keys or photos into the code or these notes.
- Never use tools that route the Anthropic key or a Claude login through other services. See [[AI tools to use and avoid]].
- Keep AI costs low.
