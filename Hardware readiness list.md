# Hardware readiness list

What [[SecurityAI]] needs before the first nights at [[J Street Gym]]. Parts list is from the Gym-security repo's Pi setup guide; prices are Jarvis's estimates from memory, not looked up (check before buying). See [[Install a new gym]] and [[Front-desk reader]].

## Per gym (about $150 to $190 without the UPS) (check)
- [ ] Raspberry Pi 5, 2GB is plenty: about $50 to $60 (check)
- [ ] Official 27W USB-C power supply: about $12 (check)
- [ ] Case: about $10 (check)
- [ ] Two high-endurance 32GB microSD cards (one in the Pi, one spare): about $10 to $15 each (check)
- [ ] USB microSD card reader: about $8
- [ ] Powered HDMI splitter, 1 in 2 out: about $15 to $25 (check)
- [ ] USB HDMI capture stick, 1080p: about $12 to $20 (check)
- [ ] Two short HDMI cables (plus a DisplayPort to HDMI adapter if the desk PC uses DisplayPort): about $10 to $15 (check)
- [ ] Network cable to the gym's router (better than Wi-Fi): about $8 (check)
- [ ] Power strip: about $10 (check)
- [ ] Optional: mini UPS if the gym loses power often: about $40 to $60 (check)

## For TJ
- [ ] A laptop: needed to write the memory card and type the setup commands, and later for Claude in Chrome. A basic or used one, about $250 to $450 (check). Could an Android phone with a USB card reader write the card instead? Unconfirmed (check).

## Online, not hardware
- Render disk so data survives deploys: needs a paid Render plan (render.yaml says the free tier can't mount a disk). Starter is roughly $7 a month (check). Without it the admin page Storage line warns that each deploy wipes data.

Nothing gets bought without TJ's OK.
